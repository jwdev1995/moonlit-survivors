# Moonlit Survivors — 게임 기획서 (GDD)

> 장르: 서바이벌 액션 로그라이트 (Vampire Survivors 계열)
> 플랫폼: 웹 브라우저 (PC 키보드 / 모바일 터치)

---

## 1. 컨셉

달빛이 내리는 밤의 숲. 끝없이 몰려오는 괴물 무리 속에서 **15분을 버티면 승리**한다.
플레이어는 **이동만** 조작하고, 무기는 **자동으로 공격**한다. 적을 처치해 경험치 보석을 모으고,
레벨업마다 3개의 선택지 중 하나를 골라 빌드를 완성한다.

### 핵심 루프
```
이동으로 적 회피 → 자동 공격으로 처치 → 경험치 보석 획득 → 레벨업 → 무기/패시브 선택 → 더 강한 웨이브
```

### 목표 플레이 경험
- 1분: "쉽네" → 5분: "보스?!" → 10분: 화면을 가득 메운 적을 빌드로 쓸어버리는 쾌감 → 15분 승리.
- 1판 15분, 재도전이 빠르게 가능한 단판 구조 (최고 기록 로컬 저장).

## 2. 캐릭터 (3종)

| 캐릭터 | 시작 무기 | 특성 |
|---|---|---|
| 기사 로렌 | 채찍 | 최대 체력 +25, 방어력 +1 |
| 마법사 이든 | 마법 화살 | 쿨다운 -12%, 공격 범위 +10% |
| 도적 세라 | 회전 칼날 | 이동 속도 +15%, 획득 범위 +20% |

공통 기본 스탯: 체력 100, 이동 속도 170px/s, 획득 반경 75px, 피격 무적 0.4초.

---

## 3. 무기 (6종, 최대 5개 장착, 각 Lv.6까지)

| 무기 | 동작 | 레벨업 효과 |
|---|---|---|
| 마법 화살 | 가장 가까운 적에게 마력탄 발사 | 탄 수 +1 / 피해 / 쿨다운 / 탄 수 / 관통 |
| 채찍 | 바라보는 방향으로 넓은 직사각형 베기 | 피해 / 양방향 / 범위 / 피해 / 쿨다운 |
| 성수 오라 | 플레이어 주변 원형 지속 피해 | 범위 / 피해 / 범위 / 피해 / 틱 속도 |
| 투척 도끼 | 위로 던져 포물선으로 낙하, 무한 관통 | 도끼 수 / 피해 / 쿨다운 / 도끼 수 / 피해 |
| 회전 칼날 | 플레이어 주위를 도는 칼날, 일정 시간 지속 | 칼날 수 / 피해 / 지속 / 칼날 수 / 피해·반경 |
| 번개 | 화면 내 무작위 적에게 낙뢰 (범위 피해) | 번개 수 / 피해 / 쿨다운 / 번개 수 / 피해·범위 |

## 4. 패시브 (9종, 최대 4개 장착)

생명의 심장(최대 HP) · 질주 장화(이동) · 힘의 룬(피해) · 시간의 모래(쿨다운) · 확장의 렌즈(범위) ·
자석(획득 반경) · 강철 갑옷(피해 감소) · 회복의 꽃(초당 회복) · 마력 증폭(모든 무기 투사체 +1)

## 5. 적

| 적 | 체력 | 속도 | 접촉 피해 | 특징 |
|---|---|---|---|---|
| 박쥐 | 9 | 100 | 6 | 빠르고 약함, 좌우로 흔들리며 접근 |
| 좀비 | 24 | 52 | 10 | 기본 근접 |
| 해골 | 42 | 68 | 12 | 중간 탱커 |
| 유령 | 30 | 125 | 8 | 매우 빠름, 서로 겹쳐서 통과 |
| 골렘 | 170 | 38 | 22 | 느리지만 단단함 |
| 보스 | 2200+ | 62 | 32 | 5분/10분/13분30초 출현, 돌진 패턴, 처치 시 보물상자 |

**시간 스케일링**: 체력 ×(1 + 분×0.12 + (분/10)²×0.5), 피해 ×(1 + 분×0.05).
화면 밖 멀리 벗어난 적은 반대편으로 재배치되어 압박을 유지한다.

### 스폰 페이즈
| 시각 | 초당 스폰 | 등장 적 |
|---|---|---|
| 0:00 | 1.2 | 박쥐, 좀비 |
| 1:00 | 2.0 | + 해골 |
| 2:30 | 2.8 | + 유령 |
| 5:00 | 3.5 | + 골렘 |
| 7:30 | 4.5 | 전 종류 |
| 10:00 | 5.5 | 해골·유령·골렘 중심 |
| 13:00 | 7.0 | 유령·골렘 러시 |

### 특수 이벤트
- 1:30 박쥐 떼(40마리 일직선 돌파) / 4:00 유령 떼
- 5:00 · 10:00 보스 / 7:00 해골 포위 링 / 12:00 골렘 포위 링 / 13:30 최종 보스(체력 3배)
- **15:00 생존 시 승리**

---

## 6. 아이템
- **경험치 보석**: 파랑(1~2) / 초록(3~5) / 빨강(6+). 획득 반경 안에 들어오면 자동 흡수.
- **드롭 (1.5%)**: 하트(체력 30% 회복) / 자석(화면 모든 보석 흡수) / 폭탄(화면 내 적 전멸).
- **보물상자 (보스)**: 즉시 무기·패시브 1단계 강화 + 체력 회복.

---

## 7. 조작
| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 터치 드래그 | 가상 조이스틱 (터치한 지점이 중심) |
| P / ESC | 일시정지 |
| M | 음소거 |
| 1 / 2 / 3 | 레벨업 선택지 고르기 |

---

## 8. UI/UX
- 상단: 경험치 바 + 레벨, 중앙 타이머, 처치 수, 장착 무기/패시브 아이콘.
- 플레이어 머리 위 체력바, 보스 체력바(하단).
- 레벨업: 게임 정지 → 카드 3장 (무기 신규/강화, 패시브) → 선택 후 재개.
- 연출: 피격 흰색 플래시, 데미지 숫자, 파티클, 보스 피격 시 화면 흔들림, 비네트.
- 사운드: Web Audio 합성음 (발사/타격/획득/레벨업/피격/보스), 음소거 설정 저장.

## 9. 비주얼
- 16×16 픽셀 아트 스프라이트를 코드로 정의(외부 이미지 없음), 2배 확대 렌더링.
- 팔레트: 어두운 남색 밤 배경(#141428 계열), 달빛 하늘색 하이라이트, 무기별 고유 색.
- 바닥은 패턴 캔버스로 무한 타일링.

## 10. 기술 설계
```
index.html      DOM HUD + 화면(타이틀/레벨업/일시정지/결과) + 캔버스
css/style.css   HUD/카드/화면 스타일
js/config.js    상수·캐릭터·무기·패시브·적·스폰 데이터 (밸런스 단일 진실 원천)
js/utils.js     수학·난수·공간 해시(충돌 가속)
js/sprites.js   픽셀 스프라이트 정의와 캔버스 캐시
js/audio.js     Web Audio 효과음
js/input.js     키보드 + 터치 조이스틱
js/entities.js  Player / Enemy / Projectile / Gem / Pickup / Particle / FloatText
js/weapons.js   무기 스탯 계산 + 발사 로직 + 무기 렌더링
js/spawner.js   페이즈별 스폰, 이벤트, 보스
js/ui.js        HUD·카드·화면 전환 DOM 제어
js/game.js      게임 루프·상태 머신·충돌·렌더링
js/main.js      부트스트랩
```
- 적 충돌은 64px 그리드 공간 해시로 O(n) 근사. 적 상한 420마리.
- 밸런스 수치는 전부 `config.js`에 있어 튜닝이 한 곳에서 끝난다.
